# MiShare (মিশেয়ার) — Android & PC Local File Transfer

**MiShare** হলো একটি দ্রুতগতির ও নির্ভরযোগ্য লোকাল ওয়াই-ফাই ফাইল শেয়ারিং অ্যান্ড্রয়েড অ্যাপ। এটি একই ওয়াই-ফাই (Wi-Fi) নেটওয়ার্ক বা হটস্পট (Hotspot) ব্যবহার করে অ্যান্ড্রয়েড মোবাইল এবং কম্পিউটারের (PC - Windows / Linux / Mac) মধ্যে যেকোনো ধরনের ফাইল (ছবি, ভিডিও, ডকস, জিপ, সফটওয়্যার/APK) আদান-প্রদান করতে পারে।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

1. **পিসি-তে কোনো সফটওয়্যার ইন্সটল করার ঝামেলা নেই (Zero PC Install):**
   - ফোনে অ্যাপটি চালু করে শুধু "Start Server" বাটনে চাপ দিলেই একটি লোকাল লিংক (যেমন `http://192.168.1.5:8888`) তৈরি হয়।
   - পিসির যেকোনো ব্রাউজারে (Chrome, Edge, Firefox, Brave) লিংকটি ওপেন করলেই ফাইল ট্রান্সফার শুরু করা যায়।

2. **মোবাইল থেকে পিসিতে ফাইল পাঠানো (Mobile → PC):**
   - ফোনে যেকোনো ফাইল সিলেক্ট করলে বা ফোনের গ্যালারি/ফাইল ম্যানেজার থেকে সরাসরি MiShare-এ "Share" করলে তা পিসির স্ক্রিনে চলে আসে।
   - পিসি ব্রাউজার থেকে সরাসরি ক্লিক করে হাই-স্পিডে ডাউনলোড করা যায়।

3. **পিসি থেকে মোবাইলে ফাইল পাঠানো (PC → Mobile):**
   - পিসি ব্রাউজারে ড্র্যাগ অ্যান্ড ড্রপ (Drag & Drop) করে যেকোনো ফাইল ছেড়ে দিলে তা দ্রুতগতিতে ফোনের `Internal Storage/Download/MiShare` ফোল্ডারে সেভ হয়ে যায়।
   - সাথে সাথেই ফোনে রিসিভড ফাইলের নোটিফিকেশন চলে আসে।

4. **সরাসরি কিউআর কোড স্ক্যান (QR Code Scan):**
   - অ্যাপের হোমস্ক্রিনে স্বয়ংক্রিয়ভাবে লোকাল কিউআর কোড প্রদর্শিত হয়। ক্যামেরা দিয়ে স্ক্যান করলেই সংযোগ স্থাপন হয়।

5. **ইন্টারনেট কোটা খরচ নেই (100% Local Transfer):**
   - এটি মোবাইল ডাটা বা ইন্টারনেট ব্যান্ডউইথ ব্যবহার করে না। আপনার রাউটার বা মোবাইলের হটস্পটের লোকাল স্পিডে (৫০-১০০+ MB/s) ফাইল আদান-প্রদান হয়।

6. **ব্যাকগ্রাউন্ড সার্ভিস ও নোটিফিকেশন (Background Service):**
   - অ্যান্ড্রয়েড ফোরগ্রাউন্ড সার্ভিস এবং ওয়াই-ফাই ওয়েক-লক (WakeLock) ব্যবহারের কারণে ফোনের স্ক্রিন বন্ধ থাকলেও বড় ফাইল ট্রান্সফার ডিসকানেক্ট হয় না।

## 📱 স্ক্রিন ও ইউজার ইন্টারফেস (UI Overview)

- **মডার্ন লাইট থিম (Light Theme):** হাই কনট্রাস্ট কালার প্যালেট (`#0F172A` এবং `#475569`)।
- **ওয়ান-ট্যাপ টগল:** এক ক্লিকে সার্ভার অনলাইন বা অফলাইন করা যায়।
- **শেয়ার্ড ফাইল ম্যানেজার:** যে ফাইলগুলো পিসির সাথে শেয়ার করা আছে তা রিয়েল-টাইমে দেখা ও রিমুভ করা যায়।
- **রিসিভড ফাইল লিস্ট:** পিসি থেকে পাঠানো ফাইলগুলো সরাসরি অ্যাপ থেকে ওপেন বা শেয়ার করা যায়।

## 🚀 কীভাবে ব্যবহার করবেন (Step-by-Step Guide)

### ১. মোবাইল ও পিসি একই নেটওয়ার্কে যুক্ত করুন:
- আপনার মোবাইল এবং পিসি উভয়কে একই ওয়াই-ফাই নেটওয়ার্কে কানেক্ট করুন।
- অথবা, আপনার মোবাইলের Personal Hotspot চালু করে পিসিকে সেই হটস্পটে কানেক্ট করুন।

### ২. অ্যাপে সার্ভার চালু করুন:
- ফোনে **MiShare** অ্যাপটি ওপেন করুন।
- **"Start Server"** বাটনে ট্যাপ করুন।
- স্ক্রিনে আপনার লোকাল আইপি অ্যাড্রেস দেখতে পাবেন (যেমন: `http://192.168.1.5:8888`) এবং সাথে একটি QR Code।

### ৩. পিসি থেকে ব্রাউজারে ওপেন করুন:
- আপনার পিসির ব্রাউজারে ওই অ্যাড্রেসটি লিখুন অথবা ক্যামেরা দিয়ে QR কোডটি স্ক্যান করুন।
- ব্রাউজারে MiShare-এর ওয়েব ড্যাশবোর্ড দেখতে পাবেন।

### ৪. ফাইল আদান-প্রদান:
- **পিসি থেকে ফোনে পাঠাতে:** ব্রাউজারের ড্রপ জোনে ফাইল ড্র্যাগ & ড্রপ করুন।
- **ফোন থেকে পিসিতে পাঠাতে:** ফোনে **"Add Files to Share"** বাটনে চাপ দিয়ে ফাইল সিলেক্ট করুন, সাথে সাথে তা পিসি ব্রাউজারের তালিকায় চলে আসবে এবং "Download" বাটনে ক্লিক করে সেভ করুন।

## 🛠️ টেকনিক্যাল আর্কিটেকচার (Tech Stack)

- **প্ল্যাটফর্ম:** Native Android (Kotlin)
- **মিনিমাম এসডিকে:** Android 7.0 (API 24) — সকল Xiaomi/Redmi/POCO ও আধুনিক অ্যান্ড্রয়েড ডিভাইসে চলে।
- **টার্গেট এসডিকে:** Android 14 (API 34)
- **সার্ভার ইঞ্জিন:** NanoHTTPD (লাইটওয়েট ও ব্যাটারি-এফিশিয়েন্ট এমবেডেড ওয়েব সার্ভার)
- **ওয়েব ফ্রন্টএন্ড:** ভ্যানিলা এইচটিএমএল৫ + সিএসএস৩ + জাভাস্ক্রিপ্ট (ফোন থেকে সরাসরি সার্ভ হয়)
- **সিআই/সিডি অটোমেশন:** GitHub Actions ওয়ার্কফ্লো (`build-apk.yml`) দিয়ে কোড পুশ করলেই স্বয়ংক্রিয়ভাবে APK তৈরি হয়।

## 📦 APK ডাউনলোড ও ইনস্টলেশন (How to Download & Install)

এই রিপোজিটরির GitHub Actions পাইপলাইন প্রতিটি পুশের সাথে স্বয়ংক্রিয়ভাবে অ্যান্ড্রয়েড APK বিল্ড করে:
1. GitHub রিপোজিটরির **Releases** অথবা **Actions** ট্যাবে যান।
2. সর্বশেষ সফল রানের **Artifacts** থেকে `MiShare-debug.apk` ডাউনলোড করুন।
3. আপনার ফোনে ইন্সটল করে সরাসরি ব্যবহার শুরু করুন।
